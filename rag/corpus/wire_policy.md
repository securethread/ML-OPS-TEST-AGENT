# NovaBank Wire Transfer Policy

Wire transfers move funds between accounts. Standard policy:

1. Outgoing wires require identity verification and a one-time passcode.
2. Daily outgoing wire limit is $25,000 for standard customers.
3. International wires require the recipient bank's SWIFT/BIC code.
4. Transfers to new payees have a 24-hour hold the first time.
5. A relationship manager must approve any wire above the daily limit.

The assistant can help you prepare a transfer, but a real transfer normally
requires these verification steps to complete.
